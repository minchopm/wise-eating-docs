# Wise Eating: Nutrients — operating procedures

Use these procedures as task-oriented reference. They describe public capabilities and verification steps, not private implementation. UI labels can vary by version.

## Procedure 1: Audit a logged meal

### Before you begin

Use a meal with known ingredient quantities.

### Steps

1. Check raw/cooked preparation for each selected food.

2. Confirm the serving basis and units before entering the quantity.

3. Include meaningful added ingredients such as oils or sauces.

4. Review missing nutrient fields separately from measured zeros.

5. Correct the log consistently before comparing it with another day.

### Expected result

The meal quantities and reference entries are internally consistent.

### If the result differs

A database value is not a lab measurement of the actual meal. Verify allergens from ingredient labels rather than relying only on a generated plan.

## Procedure 2: Reconcile pantry and shopping list

### Before you begin

Physically check the items you intend to use.

### Steps

1. Review stored quantities and expiry dates.

2. Correct consumed or discarded items.

3. Plan meals around available ingredients.

4. Inspect suggested purchases against the cupboard.

5. Confirm quantities before buying.

### Expected result

The list reflects actual stock rather than stale records.

### If the result differs

An expiry entry does not establish food safety. Correct the underlying pantry record if suggestions repeatedly include an item already present.

## Report a repeatable problem

Record app/version, device/OS, selected mode, input conditions and the smallest failing step. Distinguish expected behavior from the observed result. Use synthetic examples and omit credentials or private records.
